# 帆船赛现场控制和申诉处理

源提示词摘要：竞赛官维护组别、航线、起航时间和处罚记录，计时员提交到达数据，裁判处理抗议、重赛、弃权和成绩更正；冲突或重复处罚进入复核，操作保留时间线。

## 技术栈

React 19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62024`

## 可用流程

- 竞赛控制：起航倒计时、比赛状态切换、船队和航线查看；登记/回填/更正每场的**收船时刻**，抗议提交截止点自动按收船 + 60 分钟计算，每次更正均留痕。
- 成绩管理：录入净用时和处罚秒数，标记成绩更正并发布正式成绩。
- 抗议处理：
  - 截止点内提交的抗议直接登记进入复核队列；超过截止点提交的先进入**待定区**，仲裁补写迟交理由并确认后才能进入复核。
  - 同一份抗议（同场次、同船、同规则、同事件描述，忽略空白与大小写）重复提交时只保留最早一条。
  - 收船时刻被更正时截止点重新计算：按旧截止点已放行判定的抗议退回重判，已据此做出的成绩改动自动撤销恢复；队列归属同步调整。
  - 判定经过、迟交理由确认、成绩撤销、重复提交拦截等全部写入事件时间线，抗议对象内保留完整判定历史。
- 数据使用 localStorage 持久化，刷新页面后继续保留（旧版存档自动迁移）。
